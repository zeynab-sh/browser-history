```
cd src

java Main
```

```
cd src
javac *.java
java ListTest
java NavigationTest
java HistoryTest
```

## Git guide

Clone the project and open the folder:
```
   git clone https://github.com/zeynab-sh/browser-history.git
   cd browser-history
```

Creating your branch and adding it to Github
```
   git checkout -b feature/
   git push -u origin feature/
```

Get latest code
```
    git checkout feature/
    git pull origin main
```

Save progress
```
    git add .
    git commit -m "Add back method"
    git push
```
